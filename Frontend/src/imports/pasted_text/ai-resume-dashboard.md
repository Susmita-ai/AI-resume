## Design Requirements

Use:

* Professional SaaS dashboard aesthetic
* Strong visual hierarchy
* Clean white cards
* Light neutral background
* Blue/purple AI accents
* Rounded corners
* Subtle shadows
* Clear progress indicators
* Accessible contrast
* Consistent iconography

Do not overcrowd the dashboard.

Use realistic sample data to make the dashboard feel like a working AI product.

Create reusable components for:

* Score cards
* Progress circles
* Progress bars
* Skill chips
* Recommendation cards
* Checklist items
* Analytics cards
* Buttons
* Dashboard navigation
* Empty states

The final screen should feel like a **real production-level AI Resume Analysis platform**, suitable for a portfolio, placement presentation, and software engineering project demonstration.

Do not create Resume History, Profile, or Settings screens in this phase. Those will be created separately.
